КАК ЗАПУСТИТЬ BLOBLOX В ИНТЕРНЕТЕ (бесплатно, Render.com)
==========================================================

Что получится: одна ссылка вида https://bloblox-xxxx.onrender.com.
По ней ты и друг (с компьютера, телефона или планшета) играете в Block City, паркур и «Кто из них?».

ШАГ 1. GitHub (там будут лежать файлы игры)
  1) Зайди на github.com и зарегистрируйся (бесплатно).
  2) Справа вверху «+» → «New repository».
     Имя: bloblox. Оставь «Public». Нажми «Create repository».
  3) На следующей странице нажми ссылку «uploading an existing file».
  4) Открой папку BlobloxOnline на рабочем столе, выдели ВСЁ внутри
     (файлы и папки hide, vendor) и перетащи в окно браузера.
  5) Внизу нажми зелёную кнопку «Commit changes». Подожди, пока всё загрузится.

ШАГ 2. Render (там будет работать сервер)
  1) Зайди на render.com → «Get Started» → войди через GitHub.
  2) «+ New» → «Web Service» → выбери репозиторий bloblox → «Connect».
  3) Заполни:
       Language / Runtime:  Node
       Build Command:       npm install
       Start Command:       node server.js
       Instance Type:       Free
  4) Нажми «Create Web Service» (или «Deploy»). Через 1–3 минуты сверху появится
     ссылка ...onrender.com — это твоя игра.

КАК ИГРАТЬ С ДРУГОМ
  1) Открой ссылку, впиши имя и нажми «Создать комнату».
  2) Нажми на плашку с номером комнаты — ссылка скопируется. Отправь её другу.
  3) Друг открывает ссылку и попадает в ту же комнату.
     Комната общая для всех игр: заходите в любую игру, вы увидите друг друга.
  В «Кто из них?» можно до 10 человек; если людей меньше пяти, добавляются боты.

ВАЖНО
  * Бесплатный сервер засыпает, если 15 минут в него никто не играл.
    Тогда первый запуск ждёт до минуты, это нормально.
  * Во «Кто из них?» игру ведёт браузер того, кто зашёл первым.
    Если он выйдет, ведущим станет следующий игрок, и раунд начнётся заново.

КАК ОБНОВИТЬ ИГРУ ПОСЛЕ ИЗМЕНЕНИЙ
  1) В папке игры запусти «Обновить папку для сервера.bat».
  2) На GitHub в репозитории bloblox: «Add file» → «Upload files»,
     перетащи всё из BlobloxOnline заново → «Commit changes».
  3) Render сам обновит игру за пару минут.

ДОМА БЕЗ ИНТЕРНЕТА
  «Играть вместе.bat» в папке игры запускает тот же сервер на твоём компьютере
  (для планшета и второго компьютера в одном Wi‑Fi).
